# 다음 한칸 v0.1 — 화면 구조

## 제품 한 문장
큰 방향을 실제로 움직일 수 있는 `다음 한칸`까지 쪼개는 실행 설계 앱.

## 핵심 계층
`정체성 → 목표 → 프로젝트 → 작업 → 다음 한칸`

- 모든 항목이 반드시 정체성까지 연결될 필요는 없다.
- 독립된 `다음 한칸`을 허용한다.
- 구조 깊이는 v0.1에서 5단계로 제한한다.
- 일정/습관/캘린더/시간추적은 리뉴얼 오늘한칸의 역할로 남기고 다음 한칸에는 넣지 않는다.

## 화면

### 홈
실행 가능한 `다음 한칸`을 우선 보여준다.
- `지금 한칸` 1개를 크게 표시
- 그다음 실행 가능한 항목 목록
- 전체 계층은 숨기고 짧은 경로만 표시

### 구조
앱의 핵심 관리 화면.
- 정체성/목표/프로젝트 필터
- PC: 좌측 트리 + 우측 상세 마스터-디테일
- 모바일: 트리 선택 후 아래 상세 영역으로 이동

### 상세
정체성/목표/프로젝트/작업/다음 한칸이 같은 기본 패턴을 공유한다.
- 제목/설명
- 상위 연결
- 진행률
- 하위 항목
- 작업인 경우 `이 작업 더 쪼개기`

### 쪼개기
작업을 여러 단계로 나누고 그중 하나를 `다음 한칸`으로 지정한다.
- 하위 단계 입력
- 가장 먼저 실행할 항목 선택
- 다음 한칸 지정

### 보관함
완료/보관/중단을 삭제와 분리해 남긴다.

### 설정
v0.1 핵심 흐름에 필요한 최소 설정만 둔다.

## 현재 구현 범위
`feature/v01-screen-shell`에서는 화면 구조와 프로토타입 상호작용만 구현한다.

- 반응형 App Shell
- 모바일 하단 내비게이션 / PC 사이드바
- 홈, 구조, 보관함, 설정
- 구조 트리와 상세 선택
- 쪼개기 모달
- 빠른 생성 모달
- 데모 데이터 기반 완료 토글

## 아직 연결하지 않은 것
- Supabase CRUD
- 로그인/계정
- 실제 생성/수정/삭제
- 진행률 계산
- 보관/복구 로직
- 리뉴얼 오늘한칸과 데이터 연동

기존 오늘한칸 Supabase 데이터는 별도로 보존하며 이 화면 프로토타입에서 수정하지 않는다.
